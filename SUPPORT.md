# Support

Start with the [documentation](https://pulkitxm.github.io/hugsy/docs/) and run `hugsy doctor` in your project.

For bugs, open a [GitHub issue](https://github.com/pulkitxm/hugsy/issues/new) with the component name, macOS, Xcode, Swift, and Hugsy versions, a minimal synthetic reproduction, and the expected behavior. Redact paths, credentials, and private content from logs.

The device previews are real native captures from a dedicated iOS simulator using fictional content. Build the native sample with `sh scripts/build-ios.sh`. Components target iOS 17+. Confirm your app's behavior on the physical devices you support.

For security reports, follow [SECURITY.md](SECURITY.md). No paid support or response-time guarantee is offered.
