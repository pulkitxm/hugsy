# hugsy

Animation-heavy SwiftUI components. Copy the source. Make it yours.

Hugsy is a macOS-first component registry with a static TanStack Start website, an offline-capable CLI, and a local MCP server. There is no Swift runtime dependency.

The first collection focuses on command palettes, spring-reflow toasts, fluid tabs, magnifying docks, card stacks, and animated sidebars. No basic-control catalog.

MIT licensed. Built for macOS 14 and Swift 6.
